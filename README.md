## Course arrangement

Open [`arrangement/index.html`](./arrangement/index.html) for the Fall 2026 course overview, weekly schedule, pass requirements, and journal deadlines.

On GitHub Pages (if enabled for this repo), it will be available at `/arrangement/`.

## Class Attending Table

Source code lives in [`cat/`](./cat/). Deploy that folder as a Render Web Service with **Root Directory** set to `cat` (see root `render.yaml`).

Local run:

```bash
cd cat
npm install
npm run dev
```
